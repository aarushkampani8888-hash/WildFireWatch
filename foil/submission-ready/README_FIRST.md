# WildfireWatch — ForgeHacks upload kit

This folder contains the ready-to-paste Devpost copy, a four-minute video script, a recording checklist, and a simple architecture graphic. The hackathon requires a project title and short description, a track, a public 2–4 minute demo video, and a GitHub repository with a clear README.

## Upload checklist

1. Paste `DEVPOST_DESCRIPTION.md` into the project submission fields and select **AI + Climate**.
2. Record the walkthrough using `VIDEO_SCRIPT.md`. Keep the video between 2 and 4 minutes, publish it publicly (for example on YouTube), then paste its URL into Devpost.
3. Publish the project source on GitHub and link that repository. Start with the project-root `README.md`; it explains setup, the model, data provenance, and limitations.
4. Add `architecture.svg` as a project image if Devpost offers a gallery. Add one or two fresh product screenshots if available.
5. Complete the team roster and AI-tool disclosure in Devpost. The roster is intentionally left for the team to verify.

## Files

- `DEVPOST_DESCRIPTION.md` — title, tagline, short and long descriptions, implementation, impact, and limits.
- `VIDEO_SCRIPT.md` — natural, informal screen-recording narration with timing and visual cues.
- `RECORDING_CHECKLIST.md` — capture, publishing, and claim-check checklist.
- `GALLERY_CAPTIONS.md` — accurate, paste-ready captions for the Devpost screenshots.
- `architecture.svg` — uploadable architecture illustration.
- `WildfireWatch-source-upload.zip` — clean source snapshot with the runtime detector weights and demo examples; excludes `.env`, local reports, datasets, virtual environments, and Git history.
- `WildfireWatch-hackathon-upload-kit.zip` — a single convenience archive containing the copy, script, checklist, diagram, and source snapshot.

The source archive is a convenience snapshot, not a replacement for the required GitHub link. Do not upload `.env`, `data/`, or any operator password/API key. A public video still needs to be recorded and uploaded by the team; this kit does not claim a video already exists.
